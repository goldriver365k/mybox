# MySSD — 내 SSD 개인 파일 서버 (7단계)

Windows PC에 USB로 연결된 외장 SSD의 파일을 브라우저에서 보고 다운로드하는 프로그램입니다.
**이 PC와, 내 Tailscale 네트워크에 연결된 기기(노트북·스마트폰 등)에서만 접속할 수 있습니다.**

```
외장 SSD → Windows 메인 PC (MySSD) → Tailscale 암호화 네트워크 → 외부 PC / 노트북 / 스마트폰
```

보안은 두 겹입니다: **1차 Tailscale 승인 기기** + **2차 MySSD 로그인**.
공유기 포트포워딩, 공인 IP 노출, DDNS는 사용하지 않습니다. 파일은 외장 SSD에만 있고 클라우드로 올라가지 않습니다.

로그인 후 폴더 탐색, 다운로드, 파일 올리기(진행률 표시), 새 폴더, 사진·동영상 미리보기,
이름 변경, 이동, 휴지통 삭제·복원, 전체 검색, 최근 파일, 즐겨찾기, 사진 썸네일, 저장공간 표시, 여러 파일 선택을 할 수 있습니다.
삭제는 휴지통으로 옮길 뿐 바로 지워지지 않습니다.

> **백업에 대해**: 지금은 외장 SSD 1개만 사용합니다. MySSD는 같은 SSD 안에 복사본을 만들어 "백업"이라고 부르지 않습니다
> (SSD가 고장 나면 복사본도 함께 사라지기 때문). 실수로 지운 파일은 **휴지통**에서 복원할 수 있고,
> SSD 고장에 대비하려면 두 번째 저장장치가 필요합니다 (다음 단계에서 별도로 추가 예정).

## 1. 준비 (처음 한 번만)

1. Python 설치: https://www.python.org/downloads/
   - 설치 첫 화면에서 **"Add python.exe to PATH"** 를 반드시 체크하세요.
2. 이 `MySSD` 폴더에서 명령 프롬프트(cmd)를 엽니다.
   - 탐색기에서 `MySSD` 폴더를 열고 주소창에 `cmd` 입력 후 Enter
3. 필요한 프로그램 설치 (새 버전을 받았을 때도 다시 실행):
   ```
   pip install -r requirements.txt
   ```
   5단계부터 사진 썸네일용 **Pillow** 가 추가되었습니다. 설치하지 않아도 서버는 동작하며 사진은 아이콘으로만 표시됩니다.

## 2. SSD 경로 설정

기본값은 `E:\` 입니다. 외장 SSD 드라이브 문자가 다르면 `config.py`를 메모장으로 열어 수정하세요.

```python
SSD_ROOT = "E:\\"     # 예: F 드라이브라면 "F:\\"
```

### (권장) SSD 볼륨 이름 지정 — 드라이브 문자가 바뀌어도 올바른 SSD 찾기

Windows는 USB를 다시 꽂을 때 `E:` 였던 SSD를 `F:` 로 바꿀 수 있습니다. SSD에 이름을 붙여 두면 MySSD가 이름으로 찾습니다.

1. 탐색기 → **내 PC** → 외장 SSD 오른쪽 클릭 → **이름 바꾸기** → `MYSSD` 입력
   (또는 관리자 명령 프롬프트에서 `label E: MYSSD`)
2. `config.py` 에서:
   ```python
   SSD_VOLUME_LABEL = "MYSSD"
   ```
3. 서버 재시작

- `SSD_ROOT` 드라이브의 이름이 `MYSSD` 이면 그대로 사용합니다.
- 이름이 다르면(드라이브 문자가 바뀐 경우) `MYSSD` 라는 이름의 드라이브를 찾아, **딱 하나일 때만** 그 드라이브를 씁니다.
- 없거나 두 개 이상이면 다른 디스크를 쓰지 않고 "외장 SSD 연결이 끊어졌습니다" 오류를 표시합니다.
- 다른 USB 저장장치에 같은 이름을 붙이지 마세요.

## 3. 계정 만들기 (처음 한 번만)

```
python config.py
```

아이디와 비밀번호(8자 이상)를 입력하면 같은 폴더에 `.env` 파일이 만들어집니다.

- `.env`에는 비밀번호 **원문이 아니라 해시값**과 세션 비밀키가 저장됩니다.
- `.env`는 절대 다른 사람에게 보내거나 GitHub에 올리지 마세요. (`.gitignore`로 제외되어 있습니다)
- 비밀번호를 바꾸려면 `python config.py`를 다시 실행하고 서버를 재시작하세요.
- `.env` 대신 Windows 환경변수 `MYSSD_USER`, `MYSSD_PASSWORD_HASH`, `MYSSD_SECRET_KEY`로 설정해도 됩니다.

## 4. 실행

```
python server.py
```

이 PC의 브라우저에서 접속: http://127.0.0.1:8000

실행하면 창에 Tailscale 접속 주소도 표시됩니다. 종료하려면 명령 프롬프트 창에서 `Ctrl + C`를 누르세요.

## 5. 외부 기기에서 접속하기 (Tailscale)

Tailscale은 내 기기끼리만 암호화 터널(WireGuard)로 연결해 주는 무료 VPN입니다. 개인 사용은 무료 요금제로 충분합니다.

### 5-1. 메인 PC (SSD가 연결된 PC)

1. https://tailscale.com/download 에서 Windows용 Tailscale 설치
2. 작업 표시줄의 Tailscale 아이콘 → **Log in** → Google/Microsoft 등 **본인 계정**으로 로그인
3. Tailscale 아이콘 메뉴에서 이 PC의 IP(`100.x.x.x`)를 확인할 수 있습니다.
4. 권장: Tailscale 메뉴 → Preferences → **Run unattended** 켜기 (Windows 로그인 전에도 연결 유지)
5. 권장: Windows 전원 설정에서 **절전 모드 "안 함"** (PC가 잠들면 외부에서 접속할 수 없습니다)

### 5-2. Windows 방화벽 (메인 PC, 처음 한 번만)

`python server.py`를 처음 실행하면 "Windows 보안 경고" 창이 뜰 수 있습니다.

- **"개인 네트워크"만 체크**하고 **"공용 네트워크"는 체크하지 마세요** → [액세스 허용]
  (Tailscale 연결은 보통 개인 네트워크로 분류됩니다. 외부에서 접속이 안 되면 아래 확인 명령으로 점검하세요)

그다음 **시작 메뉴 → "PowerShell" 우클릭 → 관리자 권한으로 실행** 후 아래를 붙여넣으면,
Python 서버가 **Tailscale 주소(100.64.0.0/10)에서 오는 접속만** 받도록 방화벽 범위를 좁힙니다.

```powershell
Get-NetFirewallRule -Direction Inbound | Where-Object { ($_ | Get-NetFirewallApplicationFilter).Program -like "*python*" } | Set-NetFirewallRule -RemoteAddress 100.64.0.0/10
```

확인 (RemoteAddress가 `100.64.0.0/255.192.0.0`으로 나오면 정상):

```powershell
Get-NetFirewallRule -Direction Inbound | Where-Object { ($_ | Get-NetFirewallApplicationFilter).Program -like "*python*" } | Get-NetFirewallAddressFilter
```

> 방화벽 설정을 놓치더라도 MySSD 자체가 **이 PC(127.0.0.1)와 Tailscale 주소 외에는 모두 거부**합니다
> (같은 와이파이의 다른 기기도 "허용되지 않은 네트워크입니다"로 차단). 허용 범위는 `config.py`의 `ALLOWED_NETWORKS`.

**공유기 설정(포트포워딩)은 절대 건드리지 마세요.** Tailscale은 포트를 열지 않아도 연결됩니다.

### 5-3. 외부 기기 (노트북, 다른 PC, 스마트폰)

1. Tailscale 설치 — Windows/Mac: https://tailscale.com/download , 스마트폰: Play 스토어 / App Store에서 "Tailscale"
2. **메인 PC와 같은 계정**으로 로그인하고 연결(Connect)을 켭니다.
3. 브라우저에서 접속:
   ```
   http://100.80.20.10:8000      ← 메인 PC의 Tailscale IP로 바꾸세요
   ```
4. MySSD 아이디/비밀번호로 로그인합니다.

**장치 이름으로 접속 (MagicDNS)**: Tailscale 관리 페이지(https://login.tailscale.com/admin/dns)에서 MagicDNS가 켜져 있으면
IP 대신 메인 PC의 장치 이름을 쓸 수 있습니다. 장치 이름은 관리 페이지의 Machines 목록에서 확인하세요.

```
http://내-pc-이름:8000
http://내-pc-이름.tailXXXX.ts.net:8000    ← 짧은 이름이 안 될 때 (관리 페이지에 표시된 전체 이름)
```

### 참고

- `http://` 주소로 접속하면 브라우저에 "주의 요함"이 보일 수 있습니다. 실제 통신은 Tailscale(WireGuard)이 암호화하지만,
  **아래 6번(HTTPS)** 을 설정하면 `https://` 주소로 접속할 수 있습니다.
- Tailscale 계정에는 **본인 기기만** 추가하세요. 기기를 잃어버리면 관리 페이지(Machines)에서 즉시 제거하세요.
- 더 엄격하게 하려면 Tailscale 관리 페이지 Settings → **Device approval**을 켜서, 새 기기는 직접 승인해야만 연결되게 할 수 있습니다.
- 외부 접속을 잠시 끄고 싶으면 `config.py`의 `HOST`를 `"127.0.0.1"`로 바꾸고 서버를 재시작하세요.

## 6. HTTPS 주소로 접속하기 (Tailscale Serve)

```
외부 기기 → https://내-pc-이름.tailXXXX.ts.net (Tailscale HTTPS) → Tailscale Serve (메인 PC) → http://127.0.0.1:8000 (MySSD)
```

- 인증서는 Tailscale이 자동으로 발급·갱신합니다. MySSD는 인증서를 다루지 않습니다.
- **Serve**는 *내 Tailscale 기기에만* 공개합니다. 인터넷 전체에 공개하는 **Funnel**과 다릅니다. **Funnel은 절대 켜지 마세요.**
  (실수로 켜더라도 MySSD는 Funnel로 들어온 요청을 거부하도록 되어 있습니다)

### 6-1. 처음 한 번만 설정

1. Tailscale 관리 페이지 https://login.tailscale.com/admin/dns 에서
   - **MagicDNS** 가 켜져 있는지 확인
   - 아래쪽 **HTTPS Certificates** → **Enable HTTPS** 클릭
     (장치 이름과 tailnet 이름이 인증서 공개 기록(Certificate Transparency)에 남는다는 안내가 나옵니다. 파일 내용과는 무관합니다)
2. MySSD 서버가 실행 중인 상태에서, 메인 PC의 명령 프롬프트(cmd)에 입력:
   ```
   tailscale serve --bg 8000
   ```
   - `--bg` 는 백그라운드로 계속 유지(PC 재부팅 후에도 유지)한다는 뜻입니다.
   - `PORT`를 바꿨다면 8000 대신 그 번호를 쓰세요.
   - "Access denied" 류 오류가 나면 명령 프롬프트를 **관리자 권한으로 실행**해서 다시 입력하세요.
   - HTTPS가 아직 꺼져 있으면 켜는 방법(링크)이 안내됩니다. 1번을 먼저 하세요.

### 6-2. 확인

```
tailscale serve status
```

아래처럼 나오면 정상입니다. **`(tailnet only)`** 가 보여야 하고, `Funnel on` 이 보이면 안 됩니다.

```
https://내-pc-이름.tailXXXX.ts.net (tailnet only)
|-- / proxy http://127.0.0.1:8000
```

그다음 **Tailscale이 켜진 스마트폰/노트북**의 브라우저에서 위 `https://…ts.net` 주소로 접속 → 자물쇠 아이콘과 로그인 화면이 나오면 성공입니다.
(처음 접속할 때 인증서 발급 때문에 몇 초 걸릴 수 있습니다)

Funnel이 꺼져 있는지 확인: `tailscale funnel status` → 공개 중인 항목이 없어야 합니다.

### 6-3. HTTPS 확인 후 권장 설정

HTTPS로 잘 접속되면 `config.py`에서 아래처럼 바꾸고 서버를 재시작하세요.
이제 MySSD는 이 PC 안에서만 열리고, 외부 기기는 **Tailscale Serve(HTTPS)를 통해서만** 접속합니다.

```python
HOST = "127.0.0.1"
```

- 이 경우 `http://100.x.x.x:8000` 주소는 더 이상 쓰지 않습니다. `https://…ts.net` 주소를 쓰세요.
- 5-2의 방화벽 설정도 필요 없어집니다 (들어오는 연결을 받지 않음).

### 6-4. 끄기

```
tailscale serve --https=443 off
```

(모든 Serve 설정 초기화: `tailscale serve reset`)

### 세션 쿠키

- 로그인 쿠키는 항상 `HttpOnly`(스크립트로 읽을 수 없음), `SameSite=Strict` 입니다.
- **HTTPS 주소로 접속한 경우에만** `Secure`(HTTPS에서만 전송)가 자동으로 붙습니다.
  `http://127.0.0.1:8000` 로그인은 그대로 됩니다. 따로 설정할 것은 없습니다.

## 7. Windows 시작 시 자동 실행

`MySSD` 폴더의 **`autostart_install.bat`** 를 더블클릭하면 됩니다. (관리자 권한 불필요)

- Windows **로그인 시** MySSD 서버가 **창 없이**(`pythonw.exe`) 자동으로 시작됩니다.
  방식: 현재 사용자의 "시작프로그램" 폴더에 `MySSD` 바로가기를 하나 만드는 것뿐이며, 다른 Windows 설정은 바꾸지 않습니다.
- 외장 SSD가 나중에 연결되어도 괜찮습니다. 서버는 계속 실행되고, SSD를 연결한 뒤 새로고침하면 바로 보입니다.
- 창이 없으므로 서버 메시지는 `MySSD\logs\console.log`, 접속·작업 기록은 `MySSD\logs\myssd.log` 에 남습니다.
- 자동 실행 중에는 `python server.py` 를 따로 실행하지 마세요 (같은 포트를 쓰므로 두 번째 실행은 오류로 바로 종료됩니다).
- PC가 켜진 뒤 **로그인해야** 시작됩니다. 자리를 비워도 쓰려면 Windows 자동 로그인을 쓰거나, 로그인 후 화면 잠금만 하세요.

해제: **`autostart_uninstall.bat`** 더블클릭 (바로가기만 삭제). 이미 실행 중인 서버는
작업 관리자 → 세부 정보 → `pythonw.exe` → 작업 끝내기로 종료합니다.

확인: `Win + R` → `shell:startup` 입력 → `MySSD` 바로가기가 있으면 등록된 상태입니다.

### Tailscale 자동 시작 확인

Tailscale은 설치하면 Windows 서비스로 자동 시작됩니다. 확인 방법:

1. `Win + R` → `services.msc` → **Tailscale** 항목의 "시작 유형"이 **자동**, "상태"가 **실행 중**인지 확인
2. 명령 프롬프트에서 `tailscale status` → 첫 줄에 이 PC가 보이면 연결된 상태
3. Tailscale 아이콘 메뉴 → Preferences → **Run unattended** 가 켜져 있으면 Windows 로그인 전에도 연결됩니다

Tailscale이 꺼져 있거나 로그인되지 않아도 MySSD는 **이 PC에서(http://127.0.0.1:8000) 계속 사용**할 수 있습니다.
외부 접속만 안 될 뿐입니다.

## 사용법

### 화면 구성

- **맨 위**: `내 SSD`(홈) · 🔍 검색창 · 로그아웃 — 모든 화면에서 같은 자리
- **맨 아래 메뉴**: 🏠 홈 · 🕘 최근 · ⬆ 올리기(폴더 화면에서) · ⭐ 즐겨찾기 · 🗑 휴지통
- **홈**: 빠른 메뉴(최근 파일 / 즐겨찾기 / 사진 / 동영상 / 휴지통), **저장공간**(사용량 / 전체, 사용률 막대, 남은 공간), 내 파일 목록
  - 남은 공간 경고는 아래 "SSD 상태·저장공간" 참고. 표시만 하며 자동으로 지우지 않습니다.

### SSD 상태·저장공간 (6단계)

- **홈**: `● SSD 연결됨`, 전체 용량 / 사용 중 / 남은 공간 / 사용률 막대, 휴지통 용량.
  - 남은 공간 `LOW_DISK_WARNING_PERCENT`(15%) 이하: "SSD 저장공간이 부족해지고 있습니다."
  - `CRITICAL_DISK_WARNING_PERCENT`(5%) 이하: "SSD 저장공간이 매우 부족합니다. 대용량 업로드를 확인하십시오."
  - 경고만 합니다. **파일을 자동으로 지우지 않습니다** (휴지통도 자동으로 비우지 않음).
- **업로드 전 용량 확인**: 올린 뒤 남는 공간이 `MIN_FREE_SPACE_GB`(20GB)보다 적어지면 업로드를 시작하지 않습니다
  ("SSD 저장공간이 부족하여 업로드할 수 없습니다."). 브라우저에서 한 번, 서버에서 파일마다 한 번 더 확인합니다.
- **SSD 연결이 끊기면**: 서버는 계속 실행되고 "● SSD 연결 안 됨 / 외장 SSD 연결이 끊어졌습니다. SSD를 다시 연결하십시오." 가 표시됩니다.
  다시 연결하고 새로고침하면 바로 사용할 수 있습니다 (재설치·재시작 불필요).
- **⚙ SSD 관리**: 읽기/쓰기 가능 여부, 용량, 관리 폴더별 용량(휴지통·썸네일 캐시·임시 파일·즐겨찾기),
  [썸네일 캐시 정리](다시 만들 수 있는 썸네일만 삭제, 원본 사진은 그대로),
  [임시 파일 정리](1시간 넘게 남아 있는 끝나지 않은 업로드 조각만, 진행 중인 업로드는 제외).
  SMART(디스크 건강) 정보는 별도 프로그램과 관리자 권한이 필요해 확인하지 않습니다.

### 저장공간 분석·시스템 상태 (7단계)

- **📊 저장공간 분석**: [다시 분석]을 누르면 SSD 전체를 한 번 훑어(읽기만 함) 다음을 보여줍니다.
  - 폴더별 사용량(큰 폴더부터), 파일 종류별 용량(사진·동영상·문서·압축파일·기타, 확장자 기준),
    관리 폴더(휴지통·썸네일 캐시·임시 파일) 용량을 사용자 파일과 따로 표시
  - **큰 파일** 상위 `LARGE_FILES_LIMIT`(50)개: 파일명·크기·위치·수정일. 누르면 위치/정보로 이동하며, 이 화면에서 바로 삭제되지 않습니다
    (삭제는 기존 휴지통 방식 그대로).
  - 분석 중에는 확인한 파일 수와 현재 폴더를 보여줍니다 (전체 파일 수를 미리 알 수 없어 %는 표시하지 않음).
  - 결과는 `SSD_ROOT/.myssd_meta/analysis.json` 에 저장되어, 화면을 열 때마다 다시 훑지 않습니다 (마지막 분석 시각 표시).
    이 파일은 언제든 지워도 되는 캐시입니다 ([분석 결과 지우기] 또는 손상 시 [다시 분석]).
- **휴지통 용량**: 휴지통에 넣을 때 크기를 기록해 두고 합계를 보여줍니다 (화면마다 다시 세지 않음).
  기록이 실제와 다르다고 느끼면 휴지통 화면의 [용량 다시 계산].
- **큰 폴더**: 항목이 `FOLDER_PAGE_SIZE`(300)개보다 많으면 나눠서 보여주고 [더 보기]로 이어서 봅니다. 정렬은 전체 기준입니다.
- **🩺 시스템 상태**: SSD 연결·읽기·쓰기, 용량, Tailscale(설치·연결·IP·MagicDNS 이름), Serve(HTTPS) 설정, HTTPS 접속 확인 여부,
  서버 실행 정보, 자동 실행 등록 여부, 최근 오류.
  - 프로그램이 **확실히 확인한 것만 "정상"** 으로 표시하고, 확인할 수 없으면 "확인 필요"로 표시합니다.
  - HTTPS는 실제 HTTPS 요청이 들어왔거나 [진단 실행]에서 `https://<장치 이름>.ts.net` 에 직접 접속해 성공했을 때만 정상입니다.
  - **[진단 실행]**: 각 항목을 PASS / FAIL / 확인 필요로 보여주고 해결 방법을 안내합니다. Windows·방화벽·Tailscale 설정은 **바꾸지 않습니다**.
  - 최근 오류에는 SSD 연결 끊김, 저장공간 부족·연결 끊김으로 인한 업로드 실패, 서버 오류 같은 시스템 문제만 남습니다
    (잘못된 이름 입력 같은 실수는 📝 최근 작업에만 기록). 로그에 비밀번호·세션·쿠키는 기록하지 않습니다.

### Windows 실제 점검 체크리스트

PC에서 한 번씩 확인해 주세요 (개발 환경에서는 확인할 수 없는 항목입니다).

1. **USB 분리/재연결**: 서버 실행 중 SSD를 뽑음 → 화면에 "외장 SSD 연결이 끊어졌습니다" → 다시 꽂고 새로고침 → 정상 표시.
   🩺 시스템 상태의 최근 오류에 "SSD 연결 끊김"이 한 번 기록되는지 확인.
2. **드라이브 문자 변경**: SSD 볼륨 이름을 `MYSSD` 로 하고 `SSD_VOLUME_LABEL = "MYSSD"` 설정 →
   디스크 관리(`diskmgmt.msc`)에서 SSD 드라이브 문자를 E: → F: 로 바꿈 → 새로고침해도 파일이 보이는지, 🩺 볼륨 이름 PASS 인지 확인.
   다른 USB에 같은 이름을 붙이면 오류가 나야 정상입니다.
3. **자동 실행**: `autostart_install.bat` 실행 → PC 재시작·로그인 → 브라우저에서 http://127.0.0.1:8000 이 열리는지,
   🩺 자동 실행 "등록됨", MySSD 서버 "창 없이 실행" 표시 확인.
4. **Tailscale**: 🩺 [진단 실행] → Tailscale PASS(연결됨, 100.x IP), MagicDNS 이름 표시 확인.
5. **HTTPS**: `tailscale serve --bg 8000` 후 휴대폰(Tailscale 연결)에서 `https://<장치 이름>.ts.net` 접속 → 🩺 HTTPS 정상 확인.

### 휴지통·안전장치 (6단계)

- 휴지통 화면: 차지하는 용량·파일 수, 항목별 크기, 정렬(최근 삭제순 / 오래된 삭제순 / 큰 파일순 / 이름순).
- 영구 삭제는 **휴지통에서만**: "이 파일은 영구 삭제되며 복구할 수 없습니다." 확인란을 체크해야 삭제.
- **휴지통 비우기**: 1차 "휴지통의 모든 파일을 삭제하시겠습니까?" → 2차 "영구 삭제된 파일은 복구할 수 없습니다." 확인란 체크 후 실행.
  1차 확인 때 있던 항목만 지웁니다.
- **대량 파일 작업 확인**: 한 번에(폴더 안 파일 포함) `MASS_OPERATION_THRESHOLD`(100)개 이상, 또는 최근
  `MASS_OPERATION_WINDOW_MINUTES`(10)분 동안 합쳐서 100개 이상의 파일을 휴지통 이동·이동·이름 변경하면
  "대량 파일 작업입니다. 100개 이상의 파일이 변경됩니다." 화면에서 한 번 더 확인해야 실행됩니다.
- **📝 최근 작업**: 업로드·폴더 생성·이름 변경·이동·휴지통 이동·복원·영구 삭제·휴지통 비우기를 날짜/시간, 작업, 파일명,
  원래 위치, 새 위치, 성공/실패로 기록합니다 (`MySSD\logs\activity.jsonl`, 파일 복사 없음, 비밀번호 기록 없음).

### 5단계 기능

- **검색**: 위 검색창에 이름 일부를 입력 → SSD 전체에서 **파일·폴더 이름**을 찾고 원래 위치(`/후루룩찹찹/메뉴사진/`)를 함께 보여줍니다.
  한글·영문(대소문자 무시)·부분 검색. 파일 **내용**은 검색하지 않습니다. 결과는 최대 `SEARCH_RESULTS_LIMIT`개.
- **최근 파일**: 최근 수정된 파일을 오늘 / 어제 / 날짜별로 묶어 보여줍니다. 개수는 `RECENT_FILES_LIMIT`(기본 50).
- **사진 / 동영상**: SSD 안의 사진(JPG·JPEG·PNG·WEBP·GIF) / 동영상(MP4·WEBM)을 최근 순으로 모아 보여줍니다 (최대 `MEDIA_LIST_LIMIT`개).
- **즐겨찾기**: 각 항목 오른쪽 ☆ 를 누르면 ★ 로 바뀌고 [즐겨찾기]에 모입니다. 파일을 복사하지 않고 **경로만** 저장합니다
  (`SSD_ROOT/.myssd_meta/favorites.json`). MySSD에서 이름을 바꾸거나 옮기면 즐겨찾기도 따라가고, 휴지통으로 보내면 빠집니다.
  탐색기에서 직접 옮기거나 지운 항목은 "원본을 찾을 수 없습니다"로 표시되며 ★ 를 눌러 해제할 수 있습니다.
- **사진 썸네일**: 목록에 작은 사진이 보입니다. 처음 볼 때 한 번 만들어 `SSD_ROOT/.myssd_cache/thumbnails` 에 저장하고
  (C 드라이브 사용 안 함, 원본은 읽기만 함), 만들 수 없는 사진은 🖼 아이콘으로 표시합니다.
  캐시가 `THUMB_CACHE_MAX_MB`(기본 500MB)를 넘으면 오래 안 본 썸네일부터 자동 정리합니다. 캐시는 지워도 다시 만들어지는 것이라 안전합니다.
  목록 화면의 [▦ 사진 보기]를 누르면 썸네일 격자로 볼 수 있습니다.
- **동영상 썸네일**: 지원하지 않습니다 (FFmpeg 같은 별도 프로그램이 필요해서 설치하지 않았습니다). 🎬 아이콘으로 표시됩니다.
- **사진 보기**: [← 이전] [다음 →] [다운로드] [☆ 즐겨찾기] [정보] [닫기]. 스마트폰은 **좌우로 밀어서**, PC는 **← → 키**로 넘깁니다.
- **정보**: 이름, 종류, 크기, 수정 날짜, 저장 위치, (사진은) 가로 × 세로.
- **정렬**: 이름순(기본) / 최근 수정순 / 오래된순 / 파일 크기순 / 파일 종류순. 폴더는 항상 먼저 나옵니다. 고른 정렬은 로그인 동안 유지됩니다.
- **여러 항목 선택**: 각 항목 왼쪽 체크박스 또는 [☑ 전체 선택] → 아래에 나타나는 막대에서 [이동] / [휴지통].
  휴지통은 "선택한 N개 항목을 휴지통으로 이동하시겠습니까?" 확인 후 `.myssd_trash`로 옮깁니다 (영구 삭제 아님).
  이동할 때 같은 이름이 있는 항목은 덮어쓰지 않고 건너뛰며, 옮기지 못한 항목과 이유를 알려줍니다.

### 기본 기능

- 아이디/비밀번호로 **로그인**하면 SSD 목록이 표시됩니다. 12시간 후 또는 **로그아웃** 시 다시 로그인해야 합니다.
- 📁 폴더를 누르면 안으로 들어가고, **← 상위 폴더**로 되돌아갑니다.
- 🖼 사진(JPG, JPEG, PNG, WEBP, GIF) → 미리보기 화면 ([다운로드] [뒤로가기])
- 🎬 동영상(MP4, WEBM) → 브라우저에서 재생 ([다운로드] [뒤로가기])
- 📄 그 밖의 파일 → 바로 다운로드
- **파일 올리기**: 버튼을 누르고 파일을 고르면 바로 *지금 보고 있는 SSD 폴더*에 저장됩니다. 여러 개를 한 번에 고를 수 있습니다.
  스마트폰에서는 사진 보관함·카메라·파일 중에서 고를 수 있습니다. 올리는 동안 화면을 닫지 마세요.
  같은 이름이 있으면 덮어쓰지 않고 `photo (1).jpg`, `photo (2).jpg` 처럼 새 이름으로 저장합니다.
  한 번에 올릴 수 있는 크기는 기본 20GB이며 `config.py`의 `MAX_UPLOAD_SIZE`로 바꿀 수 있습니다.
  올리는 동안 파일 이름, 진행률(%), 전송한 용량 / 전체 용량이 표시되고 [취소]할 수 있습니다.
  업로드 중인 파일은 SSD 안의 `.myssd_temp` 폴더에 임시로 쓰이고(C 드라이브는 쓰지 않음), **끝까지 받은 것을 확인한 뒤에만** 실제 폴더로 옮겨집니다.
  연결이 끊기거나 취소하면 임시 파일은 지워지고, 기존 파일은 절대 바뀌지 않습니다.
- **새 폴더**: 버튼을 누르고 이름을 입력한 뒤 [만들기]를 누르면 지금 위치에 폴더가 생깁니다.
  `\ / : * ? " < > |` 문자와 `CON`, `NUL` 같은 Windows 예약어는 쓸 수 없습니다.
- **이름 변경** / **이동**: 각 항목 아래 버튼. 이동은 폴더를 골라 들어간 뒤 [여기로 이동]을 누릅니다.
  같은 이름이 이미 있으면 덮어쓰지 않고 오류를 표시합니다. SSD 밖으로는 옮길 수 없습니다.
  같은 SSD 안에서 이름만 바꾸는 방식이라 수 GB 동영상도 즉시 이동됩니다.
- **삭제**: 영구 삭제가 아니라 SSD 안의 `.myssd_trash` 폴더(휴지통)로 옮깁니다.
- **휴지통**: 삭제한 항목, 원래 위치, 삭제한 날짜가 보이고 [복원]할 수 있습니다.
  원래 위치에 같은 이름이 생겼으면 `이름 (1)` 처럼 새 이름으로 복원합니다. 원래 폴더가 없어졌으면 다시 만들어 복원합니다.
  작은 회색 [영구 삭제]는 경고 화면에서 확인란을 체크해야만 실행됩니다. 휴지통 전체 비우기 기능은 없습니다.
- 파일을 올리는 중인 폴더는 이동·이름 변경·삭제할 수 없습니다. 다운로드·재생 중인 파일도 Windows가 이동·삭제를 막습니다.
- `.myssd_temp`(업로드 임시), `.myssd_trash`(휴지통), `.myssd_meta`(즐겨찾기), `.myssd_cache`(썸네일) 등 `.myssd`로 시작하는 폴더는
  MySSD 관리용이라 목록·검색·최근 파일·사진/동영상 보기에 나오지 않고, 주소를 직접 입력해도 열거나 다운로드·이동·삭제할 수 없습니다.
  탐색기에서 `.myssd_trash`, `.myssd_meta` 를 지우지 마세요 (휴지통·즐겨찾기가 사라집니다). `.myssd_cache` 는 지워도 됩니다.
- 동영상은 필요한 부분만 나눠 보내므로(Range 요청) 큰 파일도 바로 재생·탐색됩니다. 변환은 하지 않습니다.
- MP4는 H.264 코덱인 경우 대부분 브라우저에서 재생됩니다. 재생되지 않는 파일은 다운로드해서 보세요.

## 자주 묻는 문제

| 화면 메시지 | 해결 방법 |
|---|---|
| 허용되지 않은 네트워크입니다 | 접속하는 기기에서 Tailscale이 연결(Connected)되어 있는지 확인. 주소는 `100.x.x.x` 또는 장치 이름 |

## 설정 (`config.py`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `SSD_ROOT` | `"E:\\"` | 외장 SSD 경로 |
| `PORT` | `8000` | 접속 포트 |
| `HOST` | `"0.0.0.0"` | `"127.0.0.1"`로 바꾸면 이 PC에서만 접속 |
| `ALLOWED_NETWORKS` | 이 PC + Tailscale 주소 | 이 범위 밖의 접속은 모두 거부 |
| `MAX_UPLOAD_SIZE` | 20GB | 한 번에 올릴 수 있는 최대 크기 |
| `LOGIN_MAX_FAILS` / `LOGIN_LOCK_SECONDS` | 5회 / 300초 | 로그인 연속 실패 시 차단 |
| `SESSION_HOURS` | 12 | 로그인 유지 시간 |
| `RECENT_FILES_LIMIT` | 50 | 최근 파일 개수 |
| `SEARCH_RESULTS_LIMIT` / `MEDIA_LIST_LIMIT` | 200 / 300 | 검색 결과 / 사진·동영상 모아보기 최대 개수 |
| `SCAN_TIME_LIMIT` | 15초 | 검색·최근·모아보기가 SSD를 훑는 최대 시간 (넘으면 찾은 데까지 표시) |
| `SSD_VOLUME_LABEL` | "" | (선택) SSD 볼륨 이름. 예: `"MYSSD"` |
| `LOW_DISK_WARNING_PERCENT` / `CRITICAL_DISK_WARNING_PERCENT` | 15 / 5 | 남은 공간 경고 기준(%) |
| `MIN_FREE_SPACE_GB` | 20 | 업로드 후 최소한 남겨 둘 공간(GB) |
| `LARGE_FILES_LIMIT` | 50 | 저장공간 분석의 큰 파일 개수 |
| `FOLDER_PAGE_SIZE` | 300 | 폴더 화면에 한 번에 보여줄 항목 수 |

| `THUMB_SIZE` / `THUMB_CACHE_MAX_MB` | 256px / 500MB | 썸네일 크기 / 썸네일 캐시 최대 크기 |

## 보안

- 공유기 포트포워딩을 쓰지 않습니다. 접속은 이 PC와 Tailscale 주소(`100.64.0.0/10`)에서만 허용됩니다.
- 로그인하지 않으면 SSD 내용을 볼 수도, 올릴 수도 없습니다. (로그인 전 업로드 요청은 파일 내용을 받기 전에 거부)
- 같은 기기에서 5번 연속 로그인에 실패하면 5분간 로그인이 차단됩니다.
- 로그아웃하면 서버에서 세션이 삭제되어, 이전 쿠키를 복사해 두었더라도 다시 쓸 수 없습니다. 서버를 재시작해도 모두 로그아웃됩니다.
- 세션 비밀키는 `python config.py`가 만든 32바이트 랜덤값이며 `.env`에만 저장됩니다.
- 삭제는 휴지통 이동이며, 영구 삭제는 휴지통의 개별 항목에서 확인 절차를 거쳐야만 됩니다.
- 기록(`logs/myssd.log`, 1MB × 최대 6개 자동 교체): 서버 시작, 로그인 성공/실패/차단, 로그아웃, 허용되지 않은 네트워크 접속,
  차단된 경로 접근·CSRF 실패, 업로드(완료/실패/취소), 새 폴더, 이름 변경, 이동, 휴지통 이동, 복원, 영구 삭제.
  비밀번호는 기록하지 않습니다. `logs/` 는 GitHub에 올라가지 않습니다.
- 비밀번호는 PBKDF2-SHA256(60만 회) 해시로만 저장·검증합니다.
- URL이나 업로드 파일명을 조작해도 `SSD_ROOT` 밖(`..`, `C:\`, Windows 폴더 등)에는 읽거나 저장할 수 없습니다.
